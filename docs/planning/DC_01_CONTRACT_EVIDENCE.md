## Priority traces: inputs, outputs, permissions, transactions, errors

- **C-001/003:** [Service.identity](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/core.py#L30) takes external ID/platform; transaction + advisory lock creates `users`, `identities`, two `wallets` and conversation, returning user ID. It has no private-pilot allowlist check. [Mini App verified_identity](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/miniapp/backend/web.py#L23) checks HMAC/freshness; login looks up existing identity, calls consent/blocked authorization and inserts hashed one-use `miniapp_sessions` in a transaction; errors become 401/403. Public/private parity and pre-registration deny are not satisfied at #17; [PR #24](https://github.com/Burn2288/FLOW-BRIDGE-GEN/pull/24) is a separate unmerged candidate.
- **C-007/008/009/015/031:** [Pricing.calculate/confirm](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/pricing.py#L279) maps provider amount/unit via rate and markup into rounded credits; `confirm_once` authorizes, locks and recalculates the quote inside a transaction, returning replacement on expiry/price change. [Wallet](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/task_wallet.py#L6) uses `FOR UPDATE`, debt/review gate and event keys; [Topups.quote](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/topups.py#L84) binds user/chat, snapshots RUB minor amount/rate and writes payment plus order in one transaction. [Stars payment](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/core.py#L325) is an XTR path. `wallets`, `ledger`, `task_price_quotes`, `task_dispatch`, `payments`, `topup_orders`: see linked migrations. Complete race/chargeback/commercial acceptance and unit decision D-02 remain open.
- **C-012/018/025:** [TaskLaunch.confirm](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/task_launch.py#L53) validates account/model and quote, reserves before dispatch, claims pending once; provider exceptions distinguish rejection and uncertain outcome; settlement occurs in transaction. [recover_interrupted](https://github.com/Burn2288/FLOW-BRIDGE-GEN/blob/d691d54e0266c3d519d66575555fa45895ef40ac/src/elevenbot/task_launch.py#L111) classifies persisted state and does not replay POST. Image notify uses a separate delivery path. A universal transactional events/outbox contract and all crash windows remain NOT_PROVEN.
