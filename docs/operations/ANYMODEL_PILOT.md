# AnyModel на тестовом стенде

В локальном `.env` закрытого стенда задайте `ANYMODEL_TEST_ENABLED=true` и
`ANYMODEL_API_KEY`. Доступ к разделу есть у `ADMIN_TELEGRAM_IDS`. Ключ
передаётся только на `https://anymodel.org/v1`. Для обновления снимка
запустите `python -m elevenbot anymodel-catalog-refresh` в контейнере бота.

Меню «Агрегаторы → AnyModel → Модели» показывает все записи ответа
`GET /v1/models`. Снимок хранится отдельно от CLODEX. При сбое бот
сохраняет последний успешный снимок по ключу и показывает статус
«Каталог устарел». Если такого снимка ещё нет, бот показывает модели
публичной витрины с неподтверждённым доступом.

Для тестового чата выбран [DeepSeek V4 Flash Vision](https://anymodel.org/en/models/deepseek-v4-flash-vision)
с точным ID `ds/deepseek-v4-flash-vision`. Кнопка доступна, когда этот ID
есть в свежем каталоге по ключу. Отправка по умолчанию выключена и
требует отдельно разрешённого `ANYMODEL_TEST_CHAT_LIVE=true`. Общая
блокировка и лимит попыток действуют. Сетевая ошибка завершает попытку.

## FIBO 2

В разделе «Генерировать изображение» подключена `anymedia/fibo-2`.
Авторизованный каталог AnyModel помечает этот ID как `kind=image`. Модель
`anymedia/fibo-lite` остаётся в общем списке.

[Контракт AnyModel](https://anymodel.org/api-docs.md?lang=en#long-running-image-requests)
описывает фоновый `POST /v1/images/generations` и опрос
`GET /v1/images/generations/{id}`. Для FIBO 2 отправляются `model`,
`prompt` и `background: true`. Метаданные модели перечисляют `size`,
`aspect_ratio` и `image`. Параметр `response_format` в них отсутствует.

При `202` бот сохраняет ID в PostgreSQL и опрашивает по `Retry-After`,
в том числе после перезапуска. При `200` валидатор принимает допустимый
PNG/JPEG из `data[0].b64_json` или защищённого URL. Изображение попадает
в «Мои работы» до отправки в Telegram. Если результат POST потерян,
задача остаётся с неизвестным исходом и POST не повторяется.

`ANYMODEL_TEST_IMAGE_LIVE` выключен по умолчанию. Для отдельно разрешённого
запуска также нужны закрытый стенд, свежий каталог по ключу и доступная
попытка в общем лимите. Выключение запуска и общая блокировка позволяют
продолжать опрос уже принятых задач.

## Закрытый видеопилот AnyModel

В разделе «Агрегаторы → AnyModel → Генерировать видео» подключён сценарий
«текст → видео» для `xai/grok-imagine-video-1.5`. Параметры первого ролика
передаются явно: 4 секунды, 480p, 16:9. При ставке 800 000 токенов баланса
за секунду оценка составляет 3 200 000 токенов (около 0,16 USD).
Ставка берётся из свежего `GET /v1/models/info` по ключу. Если цена
изменилась до подтверждения, требуется новая оценка. Если метаданных
недостаточно для расчёта, запуск закрыт.

[Контракт AnyModel](https://anymodel.org/api-docs.md?lang=en#video-generation)
определяет создание через `POST /v1/videos/generations`, опрос через
`GET /v1/videos/{request_id}` и скачивание через `GET /v1/videos/{request_id}/content`.
Идемпотентный ключ сохраняется до единственного POST. ID задания и билет
подключения сохраняются для продолжения опроса с тем же API-ключом.
Временные ошибки GET приводят к паузе. Для Grok подтверждены статусы
`pending`, `done`, `failed`, `expired`. Получение конечной ошибки при
опросе необходимо для возврата у AnyModel.
[Схема статусов xAI](https://docs.x.ai/developers/model-capabilities/video/generation).

Готовый MP4 проверяется через `ffprobe` и сохраняется в PostgreSQL до
отправки. Тот же ролик открывается из «Моих работ».
`ANYMODEL_TEST_VIDEO_LIVE` выключен по умолчанию. Отключение запуска
не прерывает опрос уже принятых заданий. При неизвестном исходе POST
автоматического повтора нет.

## Закрытый пилот озвучки AnyModel

В «Агрегаторы → AnyModel → Озвучить текст» Fish Audio S2.1 Pro Free
использует голос по умолчанию. В карточке AnyVoice можно выбрать русский
пресет из каталога по тестовому ключу. В запрос передаётся точное значение
`model` из записи голоса. Результат помечается как ИИ-озвучка.

Цена берётся из метаданных AnyModel и рассчитывается по длине текста
в UTF-16, включая пробелы и суррогатные пары. Перед подтверждением бот
показывает стоимость в токенах баланса, а при подтверждении сверяет
её заново. При неизвестном тарифе запуск закрыт.

После подтверждения выполняется один `POST /v1/audio/speech` с полями
`model` и `input`. MP3 проверяется и сохраняется в PostgreSQL до
отправки в Telegram. Сохранённый файл доступен семь дней в «Моих работах».
Повторное подтверждение и потеря ответа не приводят к повтору POST.
`ANYMODEL_TEST_SPEECH_LIVE` выключен по умолчанию.
[Контракт AnyModel](https://anymodel.org/api-docs.md#text-to-speech).
