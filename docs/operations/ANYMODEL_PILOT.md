# AnyModel на тестовом стенде

В локальном `.env` закрытого стенда задайте `ANYMODEL_TEST_ENABLED=true` и
`ANYMODEL_API_KEY`. Доступ к разделу есть у `ADMIN_TELEGRAM_IDS`. Ключ
передаётся только на `https://anymodel.org/v1`. Для обновления снимка
запустите `python -m elevenbot anymodel-catalog-refresh` в контейнере бота.

Меню «Агрегаторы → AnyModel → Модели» показывает все записи ответа
`GET /v1/models`. Снимок хранится отдельно от CLODEX. При сбое бот
сохраняет последний успешный снимок по ключу и показывает статус
«Каталог устарел». Если такого снимка ещё нет, бот показывает модели
публичной витрины с неподтверждённым доступом.

Для тестового чата выбран [DeepSeek V4 Flash Vision](https://anymodel.org/en/models/deepseek-v4-flash-vision)
с точным ID `ds/deepseek-v4-flash-vision`. Кнопка доступна, когда этот ID
есть в свежем каталоге по ключу. Отправка по умолчанию выключена и
требует отдельно разрешённого `ANYMODEL_TEST_CHAT_LIVE=true`. Общая
блокировка и лимит попыток действуют. Сетевая ошибка завершает попытку.

## FIBO 2

В разделе «Генерировать изображение» подключена `anymedia/fibo-2`.
Авторизованный каталог AnyModel помечает этот ID как `kind=image`. Модель
`anymedia/fibo-lite` остаётся в общем списке.

[Контракт AnyModel](https://anymodel.org/api-docs.md?lang=en#long-running-image-requests)
описывает фоновый `POST /v1/images/generations` и опрос
`GET /v1/images/generations/{id}`. Для FIBO 2 отправляются `model`,
`prompt` и `background: true`. Метаданные модели перечисляют `size`,
`aspect_ratio` и `image`. Параметр `response_format` в них отсутствует.

При `202` бот сохраняет ID в PostgreSQL и опрашивает по `Retry-After`,
в том числе после перезапуска. При `200` валидатор принимает допустимый
PNG/JPEG из `data[0].b64_json` или защищённого URL. Изображение попадает
в «Мои работы» до отправки в Telegram. Если результат POST потерян,
задача остаётся с неизвестным исходом и POST не повторяется.

`ANYMODEL_TEST_IMAGE_LIVE` выключен по умолчанию. Для отдельно разрешённого
запуска также нужны закрытый стенд, свежий каталог по ключу и доступная
попытка в общем лимите. Выключение запуска и общая блокировка позволяют
продолжать опрос уже принятых задач.
