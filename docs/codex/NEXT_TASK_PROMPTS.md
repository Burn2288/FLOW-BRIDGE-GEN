## Единый формат отчёта любого промпта

FACT (файл:строка и актуальный SHA) → EVIDENCE (тест/CI/live) → ROOT CAUSE (если есть реальный дефект) → CHANGE (только необходимый diff) → PHYSICAL PROOF (среда) → REGRESSION (включая код коллеги) → ACCEPTANCE (статусы + URL). Далее: состояние PR, кто ревьюировал, какая accepted main, какие личные черновики сохранены, произошло ли фактическое обновление локального клона. Никакого `PASS` без артефактов.
