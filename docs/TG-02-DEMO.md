# Первый вход в тестовом боте

Из корня рабочей копии в PowerShell:

```powershell
$env:DARKFLOW_DEMO_DOCUMENTS = '1'
uv run --locked python -m elevenbot.demo
```

Введите токен отдельного тестового бота в скрытом приглашении. Откройте личную ссылку подключения из консоли и нажмите Start. Процесс связывает демо с одним аккаунтом. Для завершения нажмите Ctrl+C.

1. Проверьте порядок вложений: `terms.md`, затем `privacy.md`. После двух ответов транспорта появляется «Принять». Нажатие открывает выбор агрегатора.
2. Команды `/terms` и `/privacy` повторно отправляют соответствующий текущий файл.
3. Чтобы проверить устаревшую кнопку, до принятия введите `/test_new_bundle`, затем нажмите прежнюю кнопку. Бот покажет обновлённую пару. Примите её.

В этом режиме документы помечены как тестовые. Подтверждение транспорта означает доставку файла со стороны Bot API. Прочтение пользователем неизвестно. Аккаунт, комплект, согласие и демонстрационные работы живут в памяти процесса. Финансовые операции отключены. Владельцем постоянного контракта и юридических текстов остаётся SL-01.

Автопроверка без Telegram-токена: `uv run --locked pytest -q tests/test_demo_documents.py tests/test_demo.py tests/test_ui.py::test_welcome_consent_start_and_menu`.
