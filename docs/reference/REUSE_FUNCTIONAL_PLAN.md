## Проверки при реализации

Рефералы: собственная ссылка, повторная регистрация, конкурирующие события, повтор начисления, возврат и долг, границы видимости. Платежи: проверка подлинности, несовпадение данных, повтор и перестановка уведомлений, неизвестный результат, атомарность, восстановление и история. Успешность этих сценариев не заявляется.

Поддержка: текст; фото, видео и документ с подписью; фото- и документный альбом; задержанные элементы; одновременные альбомы разных пользователей; текстовый и групповой ответ оператора; нужная тема; неизвестное сообщение; повтор update; сбой отправки; перезапуск при незавершённой группе; изоляция пользователей; единая история Telegram и Mini App. Дополнительно проверяются авторизация и отзыв роли, PostgreSQL, общий API и конкурентные обработчики. Сборка в памяти не считается доказательством восстановления после перезапуска.

Детальные карты и тестовые источники относятся к закрытым доказательствам. Независимый аудит требует их доступности аудитору, проверки соответствия реализации и CI для точного SHA. До этого статус PARTIAL; peer review не заменяется этим документом.
