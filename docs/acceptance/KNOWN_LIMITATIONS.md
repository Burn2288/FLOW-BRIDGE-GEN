# Известные ограничения

- Для S0 требуется исходный снимок `darkflow-gen-ubuntu` с идентификатором версии. Исходники, SQL-миграции, тесты и окружение приложения отсутствуют в базовом GitHub-снимке.
- Проверка документации оценивает файлы и ссылки. Подтверждение генерации, очереди, платежей и развёртывания требует отдельных запусков.
- Для живых проверок нужны изолированная тестовая среда и разрешённый доступ к CLODEX, Telegram и платёжной песочнице. Подробности фиксируются после инвентаризации.
