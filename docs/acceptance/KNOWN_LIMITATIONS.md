# Известные ограничения

- Импортирован исходный снимок `darkflow-gen-ubuntu`. Исторические отчёты и Git bundle оставлены в локальном архиве. Их результаты не переносятся в текущую приёмку.
- Отказ экрана статуса воспроизводится и проверяется локально. Причина сбоя живой генерации, успешная доставка пользователю и восстановление результата после рестарта пока не подтверждены.
- Путь изображений выполняется в Telegram gateway. Надёжная очередь, контракт провайдера, полное восстановление и коммерческая приёмка остаются в дорожной карте.
- Аудио может поступить через Telegram gateway при `deliveries.status = pending`. Тест с локальной заглушкой подтверждает вызов Telegram и финансовое завершение задания отдельно. Для надёжного подтверждения доставки потребуется согласовать gateway и таблицу `deliveries`.
- Для живых проверок нужны изолированная среда и согласованные условия доступа к CLODEX, Telegram и платёжной песочнице.
