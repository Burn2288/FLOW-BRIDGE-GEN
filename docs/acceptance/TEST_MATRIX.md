# Матрица приёмки

| Набор | Минимальные проверки | Начальный статус |
| --- | --- | --- |
| Документация | Относительные ссылки и обязательные документы, одинаковые команды локально и в Actions. | По результату CI на SHA PR. |
| Unit, contract, integration | Валидация, нормализация, transitions, provider stub с управляемыми задержками и отказами. | NOT_PROVEN |
| Provider live, Telegram live, E2E | Три успешные генерации подряд и один временный отказ. Реальный запрос и результат, проверка файла, сохранение, подтверждение Telegram и получение пользователем, запись в библиотеке и доступ после рестарта. Проверить отсутствие повторного списания. | NOT_PROVEN |
| Real PostgreSQL, payment sandbox | Гонки транзакций, повторный update и webhook, аутентификация вебхука, неизвестный результат платежа, сверка, принудительный отказ процесса. | NOT_PROVEN |
| Concurrency, chaos/recovery | 10/50/100 одновременных запросов на эмуляторе. Сеть, таймаут, потерянный ответ, падение worker во время платного запроса, истёкший lease, недоступная БД, полный диск, повторный старт. | NOT_PROVEN |
| Security, Ubuntu deployment | Некорректный файл, отключение провайдера, модель угроз, развёртывание и восстановление на Ubuntu 24.04. | NOT_PROVEN |

Для нагрузки измерить throughput, p50/p95/p99 задержки, ожидание очереди, ошибки, память, нагрузку БД, число одновременных вызовов и время восстановления.

`PASS`, `PARTIAL`, `BLOCKED` и `FAIL` описывают итог среза. `NOT_PROVEN` означает отсутствие достаточного подтверждения. При недоступной живой проверке P0 используйте `BLOCKED_LIVE`. Пропуск теста не равен `PASS`.

Пилот требует проверенной генерации изображений, текста и речи, нагрузки очереди в согласованных пределах, реальных финансовых тестов, восстановления результатов, безопасного поведения при неизвестном исходе, админки и диагностических отчётов, защиты секретов и воспроизводимого Ubuntu-деплоя. Закройте обязательные наборы и перечислите ограничения. Видео не блокирует пилот при доказанной расширяемости.

Формат артефактов и текущие ограничения приведены в [реестре доказательств](EVIDENCE.md) и [списке ограничений](KNOWN_LIMITATIONS.md).
