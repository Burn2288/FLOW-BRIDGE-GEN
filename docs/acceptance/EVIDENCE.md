# Реестр доказательств

Для S0 воспроизводится отказ Telegram при показе прогресса или готовности. До исправления оба сценария завершаются сетевой ошибкой Telegram. После исправления оба проходят: работа сохраняется и отправляется одним вызовом `send_photo`. Используется тестовый PNG и имитация ошибки. Команда воспроизведения — `python -m pytest -q tests/test_ui.py -k image_delivery`. Подробности есть в [аудите](../audit/AS_IS_ARCHITECTURE.md), результаты CI привязаны к SHA PR.

Для каждого среза зафиксируйте название, статус, точный SHA, находку и корневую причину, изменения и контракты, команды воспроизведения и ссылку на тест или безопасный артефакт, неизвестные факты, регрессии, риски и следующий шаг. Отдельно указывайте тип среды и факт живого вызова. Перед публикацией удалите секреты, персональные данные и приватный контент. Сырые артефакты храните вне публичного репозитория.
