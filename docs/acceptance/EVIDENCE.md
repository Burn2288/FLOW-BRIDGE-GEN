# Реестр доказательств

На этапе инициализации здесь нет результатов продуктовых прогонов. Результат CI по стартовой документации хранится в проверках её PR.

Для каждого среза зафиксируйте название, статус, точный SHA, находку и корневую причину, изменения и контракты, команды воспроизведения и ссылку на тест или безопасный артефакт, неизвестные факты, регрессии, риски и следующий шаг. Отдельно указывайте тип среды и факт живого вызова. Перед публикацией удалите секреты, персональные данные и приватный контент. Сырые артефакты храните вне публичного репозитория.
