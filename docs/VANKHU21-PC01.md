База ветки `integration/functional-test-v1` — `9479bb796041137d16bbfc14711a6753dfea2191`. Объём подтверждён по карточке PC-01 в `docs/planning/historical-tasks-v1.json`. Отдельное вложение к запросу было недоступно.

## Что изменилось

При подтверждении Pricing повторно проверяет текущую стоимость. При смене итоговой суммы или истечении срока создаётся новая оценка для подтверждения. При неизменной сумме адаптер получает принятую пользователем разбивку цены. PostgreSQL обновляет состояние и время принятия, сохраняя исходный JSON цены.
