# Дорожная карта

| Срез | Результат и условие завершения |
| --- | --- |
| S0 · P0 | Импорт проверяемой исходной версии, аудит и воспроизведение ошибки изображения. Зафиксирована точка отказа либо доказанная блокировка. |
| S1 · P0 | Реальная цепочка Telegram → CLODEX → хранилище → Telegram и библиотека. Три последовательных успеха, один временный отказ, проверка перезапуска и отсутствия повторного списания. |
| S2 · P1 | Устойчивая очередь и конкурентные задания. Проверены аварийное восстановление, лимиты и нагрузка 10/50/100 одновременных запросов. |
| S3 · P2 | Версионированные контракты и два адаптера, включая допустимый контрактный эмулятор. Подключение второго адаптера без правок Telegram-логики или финансового ядра. |
| S4 · P2 | HTTP API v1 и минимальный Mini App. Доказаны авторизация, каталог, запуск задания и получение статуса. |
| S5 · P2 | Защищённая админка, очередь, задания, ошибки, провайдеры и базовые отчёты. |
| S6 · P2 | Конкурентные финансовые проверки на PostgreSQL, моделирование угроз и проверка восстановления. |
| S7 · P2 | Воспроизводимое развёртывание на Ubuntu 24.04 и независимая приёмка ограниченного коммерческого пилота. |

Зависимый срез закрывается после подтверждения предпосылок. Для старта S0 нужен исходный снимок `darkflow-gen-ubuntu` с идентификатором версии. Распределение первых задач записано в личных ветках. Общая матрица проверок находится в [документе приёмки](acceptance/TEST_MATRIX.md).
