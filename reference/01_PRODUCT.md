# Продукт и интерфейс

## Первая версия
Личные чаты Telegram. Ввод текста сообщением. Озвучка в MP3, ограниченный проверенный каталог голосов. Покупка внутренних кредитов за Stars. История, повторная доставка, помощь. Без Mini App, регистрационной формы, телефона, пароля, реферальной программы, подписок и публичной админки.

Главное меню: «🎙 Создать озвучку», «📁 Мои работы», «💳 Баланс», «❓ Помощь».
/start: кратко описать услугу, показать условия и политику; принятие сохраняет версию условий и время. Из любого шага доступны «Назад» и «Главное меню».

## Озвучка
1. Запросить текст; проверить непустое содержимое, допустимую длину, отсутствие неподдерживаемых управляющих символов. Не менять молча смысл и пунктуацию.
2. Показать голоса с образцами, пагинацией и избранным. Пробы заранее подготовлены; нажатие «Послушать» не запускает платную генерацию.
3. Использовать проверенную модель и настройки по умолчанию. Дополнительные настройки — под отдельной кнопкой, только документированные параметры.
4. Показать длину, голос, точную розничную стоимость, срок действия предложения, доступный баланс. Кнопки «Создать за N кредитов» / «Отмена».
5. Подтверждение создаёт ровно одно задание и резервирует стоимость.
6. Ответ: «Принято. Работа №…». Не обещать неподтверждённое время.
7. Отправить MP3. Кнопки: «Другой голос» (новая платная операция с новым подтверждением), «Новый текст», «Мои работы».

Предлагаемые лимиты: 3000 Unicode code points текста, 1 активная работа на пользователя, 2 одновременных запроса к провайдеру на весь сервис, не более 10 управляющих запросов за минуту на пользователя. Последние значения корректируются по лимитам провайдера. Для тарификации используется отдельно документированная метрика; число code points не объявлять автоматически биллинговой метрикой Clodex.

## История
Показывать последние 20 работ с пагинацией, статусом, датой и стоимостью. «Получить файл» доступно только владельцу и в срок хранения. При истечении срока объяснить, что повторная генерация платная. Ошибка доставки не означает ошибку генерации.

## Баланс и помощь
Показывать доступно / зарезервировано, пакеты, историю операций. Тарифы версионируются. /terms, /privacy, /support, /paysupport доступны из помощи. Не принимать оплату без опубликованных условий и работающей поддержки.

## После MVP
Voice Changer, Speech-to-text, очистка аудио, дубляж, собственные голоса. Каждый модуль получает capability flag, отдельную валидацию загрузки, тариф, тест и документацию. Клонирование включать только с процедурой подтверждения прав/согласия. Не показывать неподдерживаемые функции как работающие.
