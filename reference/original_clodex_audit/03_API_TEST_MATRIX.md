# CLODEX API — тест-план

Статусы: `PASS` — доказанное выполнение; `FAIL` — доказанный сбой; `BLOCKED` — нет доступа/спецификации/разрешения на расход; `UNTESTED` — не запускалось. Отчёт каждого теста должен содержать UTC timestamp, sanitized request path, method, HTTP code, elapsed_ms, response type, evidence path.

| ID | Проверка | PASS | Приоритет |
|---|---|---|---|
| T01 | Адрес сервиса / TLS | Ответ и валидный TLS | P0 |
| T02 | Ключ / auth | Официальный endpoint отвечает авторизованно | P0 |
| T03 | Список моделей | Доступны model IDs и capabilities | P0 |
| T04 | Наличие TTS | Документирован маршрут и работающая модель | P0 |
| T05 | Список голосов | Возвращается voice ID + параметры | P1 |
| T06 | Первая генерация | Воспроизводимый аудиофайл | P0, платный тест только по разрешению |
| T07 | Учёт стоимости | Фактическое списание измерено | P0 |
| T08 | Ограничение длины текста | Понятная ошибка лимита | P1 |
| T09 | 401/403 | Корректное описание без утечки ключа | P0 |
| T10 | 429 | Backoff/Retry-After без дублей | P1 |
| T11 | 5xx и неопределённый исход | Нет двойного платного вызова | P0 |
| T12 | Бинарный аудиоответ | Правильный Content-Type и bytes | P0 |
| T13 | Отключение провайдера | Worker сохраняет job в понятном статусе | P1 |
| T14 | Voice Changer | Контракт + реальный результат | P2 |
| T15 | Dubbing | Контракт + polling + результат | P2 |
| T16 | Контроль доступа к голосам | Нет неавторизованного клонирования | P0 если функция включена |
| T17 | Billing webhook/ledger | Нет двойного списания при повторах | P0 |
| T18 | Удаление временных файлов | По политике хранения | P1 |

## Фиксация доказательств
`reports/YYYYMMDD_HHMM/test_id.json`, скриншот или sanitized HTTP response. Не хранить тела приватного пользовательского текста без необходимости.

## Режим без токена
T01 можно выполнить без ключа. T02–T05 нужны документированные маршруты/ключ. T06 и выше требуют отдельного подтверждения бюджета.
