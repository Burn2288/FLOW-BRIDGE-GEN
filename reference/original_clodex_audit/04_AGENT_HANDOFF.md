# Задание разработчику/Antigravity — CLODEX API

Цель: интегрировать clodex.xyz в Python Telegram-бот для ElevenLabs-подобной озвучки. Не путать с github.com/bman654/clodex и clidex.dev.

## Порядок работ
1. Сначала прочитай 01_AUDIT.md, 02_INTEGRATION_GUIDE.md, 03_API_TEST_MATRIX.md.
2. Проверь доступную официальную документацию CLODEX и реальные авторизованные маршруты. Не подменяй их API ElevenLabs/OpenAI.
3. Создай `ClodexAdapter` с абстракцией возможностей; недоступные capabilities верни как unsupported.
4. Сначала тесты без денежных списаний; платный тест только после явного разрешения владельца.
5. Отслеживай каждое списание, MIME аудио, response status, request id, идемпотентность.
6. Не принимай MOCK за LIVE PASS.
7. Не передавай ключи в логи, скриншоты, исходники или выдачу пользователю.
8. После TTS LIVE PASS подключай телеграм-процедуру и тестируй на одном пользователе. Платёжный модуль подключать только после проверки учёта расхода и возвратов.

## Правило диагностики
На каждом этапе: VERIFY → PASS / FAIL / BLOCKED. При FAIL исправить минимальный участок кода и повторить ограниченный тест. При BLOCKED описать точный недостающий вход (документ, API-key, бюджет). Не придумывать поля и не добавлять несуществующие API endpoints.
