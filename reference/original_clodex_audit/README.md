# CLODEX API — пакет для разработки
Дата: 2026-11-03

Это инженерный пакет для работы с **clodex.xyz**. Он намеренно отделяет подтверждённые сведения от непроверенных предположений. Никаких действующих ключей в архиве нет.

## Содержание
- `01_AUDIT.md` — источники, статус информации, риски, матрица методов.
- `02_INTEGRATION_GUIDE.md` — порядок интеграции, архитектура, безопасность, эксплуатация.
- `03_API_TEST_MATRIX.md` — проверочные тесты с критериями PASS/FAIL/BLOCKED.
- `04_AGENT_HANDOFF.md` — инструкция агенту-разработчику.
- `probe_clodex.py` — безопасная диагностическая утилита (stdlib Python), без платных генераций.
- `.env.example` — образец переменных окружения (не содержит ключей).

## Быстрый старт Windows
1. Установить Python 3.10+.
2. Создать переменную окружения `CLODEX_API_KEY` в ТЕКУЩЕЙ PowerShell-сессии: `$env:CLODEX_API_KEY = Read-Host 'CLODEX API key'` (ввод отображается; для реального секрета предпочтительно использовать менеджер секретов).
3. `python .\probe_clodex.py --base-url https://clodex.xyz/v1 --list-models`
4. Проверить `probe_report.json` (ключ в отчёт не включается). Скрипт **не выполняет платных запросов**.

Обратите внимание: URL `/v1/models` взят из распространённого OpenAI-совместимого протокола, однако для конкретно clodex.xyz его работоспособность ещё не подтверждена живым запросом с действительным ключом.
