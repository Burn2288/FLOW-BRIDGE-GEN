# ElevenBot — пакет для разработки
Дата: 03.11.2026. Язык интерфейса: русский.

Цель: простой платный Telegram-бот для озвучки через Clodex с возможностью подключения MAX к общему ядру.
Это техническое задание и проектные материалы, НЕ готовый работающий бот. DDL — исходная миграция для доработки; шаблоны конфигурации не подтверждают доступность API.

## Порядок чтения
1. 01_PRODUCT.md — границы продукта и пользовательские сценарии.
2. 02_ARCHITECTURE.md — модули и структура проекта.
3. 03_DATA_AND_MONEY.md и schema.sql — данные и деньги.
4. 04_JOBS_AND_FAILURES.md — выполнение и восстановление.
5. 05_PROVIDER_CONTRACT.md — подключение Clodex/ElevenLabs.
6. 06_SECURITY.md — обязательные ограничения.
7. 07_TELEGRAM_PAYMENTS.md — Telegram и Stars.
8. 08_MAX.md — переносимость.
9. 09_DEPLOYMENT.md — эксплуатация.
10. 10_ACCEPTANCE.md — приёмка.
11. 11_IMPLEMENTATION_PLAN.md — этапы разработки.
12. AGENT_HANDOFF.md — задание разработчику.
13. SOURCES.md — официальные источники и границы проверки.

original_clodex_audit/ содержит предыдущие материалы без исправления их содержания. Их URL, модели и методы-кандидаты НЕ считать проверенными. При конфликте с текущим пакетом использовать текущие документы; официальные контракты провайдеров проверять перед реализацией.

## Нерешённые входы
- Официальный контракт Clodex: TTS, голоса, авторизация, billing, лимиты, статусы и идемпотентность.
- Цена закупки и розничные пакеты: до проверки стоимости платные продажи выключены.
- Токен BotFather, сервер, секреты: передаются вне исходников и публичных чатов.
- Реквизиты владельца, условия услуги, политика обработки данных, контакт поддержки.
- MAX: доступ владельца к созданию ботов, актуальные требования платформы и отдельное решение по оплате.

Предложенные числовые лимиты — стартовые настройки продукта, а не официальные лимиты провайдеров.
