# Mini App в нижней клавиатуре

[PR №17](https://github.com/Burn2288/FLOW-BRIDGE-GEN/pull/17), SHA стенда `f69fd5cf19957c3d35ec02e1e08492881663f2c7`. Бот и Mini App пересозданы в существующем flowbridge-live-smoke, локальный HTTP вернул 200. Генерация, оплата и пополнение закрыты. PostgreSQL и тома сохранены.

В обоих режимах клавиатура при заданном MINIAPP_URL формирует полноширинную кнопку «Приложение» перед «🌐 Агрегаторы». Синее меню регистрируется как MenuButtonCommands. При пустом MINIAPP_URL строка скрыта. 34 целевых теста прошли, в том числе /start, /menu, размещение кнопки и inline-вход по /miniapp. Telegram не передаёт initData при запуске из reply keyboard. В этом случае «Каталог» показывает подсказку /miniapp → «Открыть каталог», подписанный вход использует inline web_app.

На стенде нет внешнего HTTPS. Нужен готовый HTTPS URL с прокси на 127.0.0.1:8091 либо выделенный поддомен и доступ к DNS и внешнему reverse proxy с доверенным сертификатом. Telegram Bot API после обновления отвечал таймаутами и Bad Gateway, поэтому тип меню на стороне Telegram повторно не подтверждён. Последняя успешная проверка до обновления показывала commands. Скриншот кнопок и ручные проверки в Telegram Android/Desktop ожидают приёмки.
